# Piano Trainer

Aplicación web local para practicar lectura de piano con un teclado MIDI.

## Desarrollo

```bash
npm install
npm run dev
```

Abre la URL de Vite en Chrome o Edge (`localhost`). Concede permiso MIDI cuando el navegador lo pida.

Sin teclado físico puedes usar las teclas `A W S E D F T G Y H U J K` (Do4–Do5).
